# Gourmet Haven Coffee Shop

مرحبًا بك في موقع **Gourmet Haven** – وجهتك المثالية لعشاق القهوة والحلويات!

## وصف الموقع
موقع عصري وجذاب لمقهى يقدم أفضل أنواع القهوة والمخبوزات الطازجة، مع عروض خاصة، وحجز طاولة، ومعلومات التواصل والموقع الجغرافي. يتميز الموقع بتصميم متجاوب وألوان دافئة مستوحاة من أجواء المقاهي.

## الميزات
- عرض قائمة القهوة والحلويات مع صور وأسعار
- قسم العروض الخاصة الأسبوعية
- حجز طاولة أونلاين بسهولة
- معلومات التواصل وروابط الشبكات الاجتماعية
- خريطة تفاعلية للموقع
- قسم تعريفي بالمبرمج

## التقنيات المستخدمة
- **HTML5**
- **CSS3**
- **JavaScript** (للحركات البسيطة)
- خطوط وأيقونات [Font Awesome](https://fontawesome.com/)

## طريقة التشغيل
1. قم بتحميل جميع ملفات المشروع (HTML, CSS, الصور، إلخ).
2. افتح ملف `index.html` في متصفحك المفضل.
3. استمتع بتجربة الموقع!
